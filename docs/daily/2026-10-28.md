## What I Learned

### Requests and errors

- A request without a timeout can wait forever, so every `requests.get` needs a timeout.
- Errors to handle separately: `Timeout`, `ConnectionError`, `HTTPError`.

### HTML cleaning

- The content for the RAG is inside the `<main>` tag. `SoupStrainer(name="main")` passed to `BeautifulSoup(parse_only=...)` keeps only that tag.
- Code snippets for other languages sit in `lang-variant` blocks. The cleaner keeps only the configured language (Python).
- Removing a link while keeping its text is `unwrap()`. Removing the whole tag with its text is `decompose()`.

### Converting

- `html-to-markdown` converts the cleaned HTML to Markdown. The result is good. A few tuning options exist (see Next Steps).

## What I Implemented

- Fetcher: timeout on the request and exception blocks for timeout, connection error and HTTP error.
- Paths: absolute paths built in the code instead of relative paths.

- `html_post_processing.py` (cleaning): keeps only `<main>`, keeps only the Python snippets, removes header anchors and links but keeps the link text. A few links still remain, which is not a problem for now.
- `convertor.py`: converts the cleaned HTML to Markdown and saves it in `data/processed_md`.
- `RAGOrchestrator` now runs fetch, clean and convert for every service in `config.json`.
