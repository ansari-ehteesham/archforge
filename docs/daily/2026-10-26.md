## What I Learned

### Project and tooling
- A `src/archforge/` layout with a `[build-system]` makes the project a real package. `uv sync` installs it, and `import archforge` works from anywhere.
- The CLI command is the script name in lowercase: `uv run archforge --pipeline RAG --rerun true`.
- GitHub is moving `ubuntu-latest` to Ubuntu 26.04 (19 Oct to 19 Nov 2026). `setup-python` has no Python 3.12.4 build for it, so a pinned runner is safer.

### RAG
- RAG = cut docs into chunks, turn each chunk into an embedding, store them in a vector database, then find the chunks closest in meaning to a question.
- ChromaDB runs locally, is free and keeps data in files.
- Rules must always apply, but a RAG search may not return them. So rules go in the system prompt, and the RAG holds only reference docs.
- LlamaIndex fits retrieval-heavy apps (many file types, rerankers, routers). LangGraph fits agent workflows (loops, saved state, human approval).
