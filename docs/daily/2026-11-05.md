## What I Learned

### LangChain

- `create_agent` (from `langchain.agents`) takes a model, a list of tools and a system prompt, and runs the model in a tool-calling loop until it has an answer.
- Model name format: `provider-name:model-name` (for example `google_genai:gemini-3.5-flash-lite`).
- A tool is a Python function. The model needs the argument names and types, the return type and the docstring (the description).
- One question that uses one tool makes two model calls: model (asks for the tool), tool, model (writes the answer). Each model call is one Gemini request, which counts against the free-tier limits.
- `create_agent` is built on LangGraph. Deep Agents is a higher-level agent built on LangChain agents. Not studied yet.

### LangSmith

- LangSmith is an observability platform (also used for evaluation). For one agent run it shows the user input, each model call, the tool call with its arguments, the tool result, the final answer, latency and token counts.
- The free Developer plan has 1 seat and 5k base traces per month.
- Setup needs only environment variables (`LANGSMITH_TRACING`, `LANGSMITH_API_KEY`, `LANGSMITH_ENDPOINT`, `LANGSMITH_PROJECT`). No code change is needed.
- US accounts use the default endpoint `https://api.smith.langchain.com`.
- A workspace holds projects, datasets and prompts. Key types: Personal Access Token (has all my user's permissions), Service Key, Tracing Only (write-only).
